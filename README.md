# LSTM Next Word Predictor

An LSTM-based next-word prediction application using a trained TensorFlow model.

Features:
- Predicts the next word from the entered text.
- Displays suggested words with probabilities.
- Supports adding a suggested word by pressing Enter.
- Uses a trained LSTM model and tokenizer.
